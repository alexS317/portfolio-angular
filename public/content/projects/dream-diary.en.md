I started building this app originally because I wanted to learn lucid dreaming, but always struggled to remember my dreams. In Dream Diary, users should be able to track their dreams in a calendar, mark whether or not they had a lucid dream and write down details about what they remember from it. I also wanted to use it as an opportunity to learn how to implement user authentication and use Firebase as a back-end.

In its current state, the app is still very much a work in progress, and unfortunately I did not have the time to continue working on it for a longer while. I still hope that I will be able to do so though at some point, as I would want to be able to actually use it.
