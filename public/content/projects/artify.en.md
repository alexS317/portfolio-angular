I created this website during my second Creative Code Lab (two week intensive project at the end of the semester), which focused on full-stack web development. The goal was to make a simple website (for example a webshop, a social media clone, etc.) where users could sign up, customise their profile, and perform other types of interactions. I created a small art sharing platform (inspired by DeviantArt) where people could upload their drawings. I used the Express framework and a MySQL database to store the user data. The design was also made by myself and for the example images which I used for testing, I simply used various pieces of my own fan art drawings that I had done in the recent months.

Unfortunately, the database and hosting that was provided for the project by the university is not available anymore, which is why it is currently not accessible online. If you clone the repository and follow the instructions in the README file, you can test it locally though and it should work just fine there. I have also included a video which I recorded as part of the assignment, where I show the most important parts of the application.
