The main motivation to start this project was actually frustration. I was very annoyed that the default music player on my phone included ads, despite me just wanting to listen to music I had stored locally on my device. So I decided to just code my own music player app instead!

I threw this together in a very short span of just a few days as I wanted to be able to use it as soon as possible. Therefore I admit it is rather messy, the basic functions work, but there are some bugs and is definitely in need of a thorough refactoring when I have the time for it. Still, I think it helped me getting more familiar with Flutter, as I also used some packages and techniques that I did not know before yet.
